# Game Product Planning

Use this workflow for product or production decisions about the game.

1. Describe the target player, unmet need, current evidence, and the outcome the player should experience.
2. Separate confirmed facts from assumptions. Identify the cheapest useful way to validate uncertain assumptions.
3. Rank candidate work by player impact, effort, technical and design risk, dependencies, and confidence in the evidence.
4. Define an MVP with explicit inclusions, exclusions, acceptance criteria, and a reversible first milestone.
5. Choose a small set of measures that match the goal: completion, repeat play by choice, session length, return rate, perceived fairness, or fun rating. Define a baseline and observation window when data exists; do not invent measurements.
6. Consider progression, seasons, events, and LiveOps only when they add durable player value. Avoid artificial urgency, coercive streaks, or reward schedules that obscure the game's value.
7. Return a short decision brief and ordered backlog. Flag decisions about rules, architecture, online services, or scope for user approval before implementation.
